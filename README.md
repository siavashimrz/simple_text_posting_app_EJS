# MyBlog

A simple blog application built with Express.js and EJS.

The app allows creating, viewing, editing, and deleting text-based blog posts. It is intentionally simple and does not include user accounts, authentication, or a database.

## Features

- Create blog posts
- View blog posts
- Edit blog posts
- Delete blog posts
- About page

## Tech Stack

- Node.js
- Express.js
- EJS
- CSS
- JavaScript

## Notes

This project was created for learning and practice purposes.

Posts are stored in memory and are lost when the server restarts. There is no authentication or database integration.

## Installation

```bash
npm install
node index.js
```
